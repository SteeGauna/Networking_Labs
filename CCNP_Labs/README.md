# CCNP Labs

This folder contains the labs I configured while working towards my CCNP. As I learned new concepts, I found that I understood them much better when I actually took the time to build and configure the labs from scratch rather than just reading about them. So, I decided to document my work here as a way to track my progress, revisit concepts, and also get familiar with the culture of using Git and GitHub.

Hopefully, if you're also working towards your CCNP, you'll find some of these labs useful. Whether you're looking for ideas for your own labs, trying to understand a particular concept, or just want to see how someone else approached a topic, feel free to have a look around. This folder includes labs covering **HSRP, OSPF, BGP, EIGRP, VRRP, VTP, Cisco SD-Access**, and other networking concepts that I've worked through along the way. I’ll continue adding to this as I learn and build more.

The .pkt files that are contained within this repository can be opened using the Cisco Packet tracer application.
