# CCNP Labs

This folder contains the labs that I configured as I worked towards my CCNP. As I learnt about new concepts, I found that I understood concepts more if I were to configure the Labs from scratch.

So I've created a folder in hopes to create a culture of documenting my work and maybe help other people out as they are prepping for their CCNP exam.

This folders includes labs that encompasses:
 - HSRP
 - OSPF
 - BGP
 - EIGRP
 - VRRP
 - VTP
 - Cisco SD-Access
