# CCNP Labs

This folder contains the labs that I configured as I worked towards my CCNP. As I learnt about new concepts, I found that I understood concepts more if I were to configure the Labs from scratch.

So I've created a folder to document my work and also get use to the culture of Git and Github.

Hopefully, some of you viewing this may also be preparing for your CCNP and I'll be happy that theses documents will help you in any way

This folders includes labs that encompasses:
 - HSRP
 - OSPF
 - BGP
 - EIGRP
 - VRRP
 - VTP
 - Cisco SD-Access
